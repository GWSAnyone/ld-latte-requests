Авторизация и токены

Подключение и поддержание доступа

Владелец входит самостоятельно. Сервер получает и хранит токен, затем обновляет его до истечения срока.

01 / Подтверждение
Один вход

Instagram Login выдаёт одноразовый код.

Код действует 1 час.
02 / Обмен кода
~ 1 час

Короткий Instagram User token.

Сразу обменять на долгоживущий.
03 / Рабочий доступ
~ 60 дней

Долгоживущий токен для сбора статистики.

Срок учитывать по expires_in.
04 / Обновление
Каждые 30 дней

Рекомендуемый интервал обновления.

Refresh: токен действующий, старше 24 часов.
Разрешения для статистики

instagram_business_basic
instagram_business_manage_insights

Права на публикацию, сообщения и комментарии не нужны.
При истечении или отзыве

Уведомление → повторный вход

Истёкший токен не обновляется. Ошибка одного аккаунта не останавливает сбор остальных.

План проверки

Контрольные точки перед запуском

Каждый этап завершается проверяемым результатом. Проверки повторяются для всех аккаунтов.

01 / ДОСТУПВладелец + специалист

Авторизация

Проверить вход, отказ, выданные права и срок токена.

✓ Аккаунт разрешил чтение статистики
02 / ИДЕНТИФИКАЦИЯ

Правильный аккаунт

Сверить username и IG ID; прочитать профиль и одну публикацию.

✓ Данные принадлежат нужному аккаунту
03 / ПОКАЗАТЕЛИ

Доступность метрик

Проверить период, формат и сравнить с Instagram с учётом задержек и рекламы.

✓ Метрики и ограничения согласованы
04 / ХРАНЕНИЕ

Повторный сбор

Загрузить дважды, подключить второй аккаунт, проверить даты и разделение данных.

✓ Нет дублей и смешения аккаунтов
05 / РАСПИСАНИЕ

Обновление доступа

Проверить refresh токена старше 24 часов и несколько запусков по расписанию.

✓ Доступ продлён, интервалы не пропущены
06 / ВОССТАНОВЛЕНИЕ

Сбой одного аккаунта

Отключить один доступ, проверить уведомление, повторный вход и догрузку.

✓ Остальные аккаунты продолжают сбор
✓

Критерий запуска: согласованные метрики доступны, сохраняются без дублей, доступ обновляется, ошибки видны ответственному.
